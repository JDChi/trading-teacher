# Learned Trading Concepts

Track concepts the user has studied and where review is needed.

## Category Taxonomy

- 数学与概率基础: 期望、概率、模拟、统计规律等底层工具。
- 策略范式与因子: 具体交易/投资范式、因子、套利逻辑、估值框架。
- 风险与资金管理: 仓位、回撤、安全边际、非对称结构、止损等。
- 数据与验证工程: 数据质量、回测验证、样本外、成本、策略衰减等。
- 市场认知与交易哲学: 市场如何运行、参与者行为、反身性、易错性等。
- AI 辅助研究: AI 在资料、数据、代码、情绪、特征发现中的辅助角色。
